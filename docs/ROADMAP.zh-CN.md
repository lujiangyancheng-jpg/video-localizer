# 分阶段开发路线

这是开发目标，不代表已经实现，也不承诺发布日期。每阶段先验证质量和资源占用，再扩大范围；基础安装包不默认加入新增大模型。

## 一：可靠的本地基础（0.7.0.18）

隔离本地任务和媒体代理配置；按任务最新失败诊断；损坏配置提供修复提示。补回归测试，并验证升级保留现有模型与项目。

## 二：短片多语言配音（下一开发重点）

1. 先基于已审核字幕生成短片试听，不直接承诺整片一键完成。
2. 实现可替换的语音合成接口；评估离线模型的许可、体积、中文／英文听感及 CPU／GPU 兼容性后再选择默认实现。
3. 先用预设声音，不默认克隆任何人的声音，明确标记合成配音。
4. 按字幕时间轴处理停顿、语速与重叠，提供原片／译文／配音对照试听。
5. 短片效果通过后，再支持整片、分段恢复、取消、资源限额和独立音轨导出。

原声压低混音不等于背景音乐分离；没有验证音源分离前，不声称能去掉原人声并完整保留音乐。进入整片阶段前，听感、术语发音、对齐、耗时和内存占用应有可复现结果，不要求更新稳定显卡驱动。

## 三：结合画面翻译

先让用户选定关键帧和 OCR 文本作为翻译上下文，显示来源并允许纠正，再评估可选视觉模型。不用模型猜测替代原片事实，不自动覆盖已审核字幕。

## 四：多语言、多画幅交付

同一项目复用识别、翻译和配音缓存。先支持明确的横／竖屏方案，再研究主体跟踪与字幕避让。原素材、人工修改与各语言输出分别保留。

## 后续探索

带时间引用的视频知识库、对话式局部修改、可解释的精彩片段推荐。前述流程稳定后再安排，不一次性引入所有模型。
